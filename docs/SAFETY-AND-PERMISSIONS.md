# 權限、資料與進階操作

App沒有INTERNET權限、廣告／遙測SDK或自動上傳。建置工具需要下載依賴，與App本身網路能力不同。

| 宣告／能力 | 用途與界線 |
| --- | --- |
| ACCESS_NETWORK_STATE／ACCESS_WIFI_STATE | 首頁網路狀態及系統網路設定捷徑；本版不顯示SSID |
| READ_EXTERNAL_STORAGE（至API32） | 相容舊系統的使用者選圖／系統圖片備份；需要時才請求，允許不代表同意套用 |
| SET_WALLPAPER | 使用者明確確認後設定系統背景；不代表可寫最早logo |
| WRITE_SECURE_SETTINGS | 繼承的可選遙控／設定修復能力，屬受保護權限；普通安裝不自動獲得，開源建置工具不授予 |
| yandex.tv.permission.ACCESS_TV_SOURCE | 繼承的YaOS輸入來源相容能力；其他系統忽略 |
| Accessibility／Notification listener | 繼承的可選遙控器相容服務；需使用者或系統獨立允許，普通HOME不要求自動開啟 |
| Root | 僅供使用者明確確認的開發工具；不取得Root、不繞過SELinux或授權對話框 |

使用紀錄、設定、使用者匯入的圖片與操作收據留在App私有儲存或使用者選定的匯出位置。App宣告allowBackup=false；使用者應自行保管重要匯出內容，不把私人資料提交GitHub。

## Root及開機外觀

開啟設定、預覽、取消均不表示授權Root寫入。保留既有交易狀態、來源／備份雜湊、UID／路徑／格式、明確確認、一次派送、回讀及PENDING／UNKNOWN停止守衛。

最早logo操作可能寫入block device的窄範圍，非原子操作，斷電可致無法開機。影片／系統桌布／最早logo是獨立交易，沒有三者全部原子提交承諾。沒有匹配的離線救援與設備外備份時，不應進行寫入。

無線ADB可在缺少主機驗證或網路限制的韌體上暴露高權限介面，僅在可信環境自行決定啟用。自動重啟後恢復ADB、獨立離線HOME回退與完整韌體救援均不屬已保證能力。

公開版不包含私人事故的交易ID、原素材／分割區雜湊收據。單次舊事故候選採用綁定已替換為不可作為真實恢復依據的合成測試值；相關舊事故遷移入口不構成通用解鎖機制。韌體函式庫的內容雜湊守衛保留，這些是固定檔案相容性條件，不是設備私鑰。
