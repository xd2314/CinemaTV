# 相容範圍與驗證界線

## 一般首頁

- Android API26以上，橫向顯示；電視DPAD遙控器是主要操作方式。
- 私人原型曾在PO指認的安博9與10系統使用；商品名不保證晶片、API、HOME政策或韌體一致。
- 本公開來源保留v71主要程式，但恢復經PO授權的原始預設圖片、整理簽章與歷史收據；公開變體尚未實機驗收，不能直接沿用私人版PASS。
- 本機回歸含Robolectric Native Graphics API29／31及720p／1080p；這不是完整Android模擬器／實體遙控器測試。
- 第三方App依安裝狀態出現，預設套件名稱只是原型的啟動偏好，不包含或下載影音App與內容。

## 各能力分開判定

| 能力 | 條件與限制 |
| --- | --- |
| HOME／DPAD／App清單 | 不需Root；系統須支援第三方HOME |
| 自訂首頁桌布／最近項目圖 | 使用者選檔、App私有儲存；不同檔案管理器仍需確認 |
| 系統過場桌布 | 依Android API及可讀回備份條件；不是最早開機logo |
| 啟動無線連接 | 需設備已有可用`su 0`與明確確認；不會替設備取得Root |
| 開機影片 | 實驗性；需符合當次路徑、讀者權限／內容守衛及備份讀回 |
| 最早開機圖片 | 高風險、限定FAT/BMP資源布局及對齊window；不是通用分割區工具 |
| 完整韌體恢復 | 沒有提供或驗證 |
| 待機／重啟／長期／低RAM壓力 | 此公開變體未驗證；需獨立實測 |

保留有界圖示快取、桌布降採樣、最新請求取消、退場頁最多一個及暫停清理。不要把短期PSS穩定當成長期無洩漏保證，也不要把安博10量測直接套用到安博9。設定頁不提供常駐記憶體面板。
