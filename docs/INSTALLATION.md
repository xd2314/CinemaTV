# 自行安裝與回到原廠HOME

本文件只提供人工程序，不會自動操作設備。

1. 確認自己擁有並獲准管理設備，記錄原廠HOME的實際套件／Activity，保留原廠Launcher與原廠影音服務。
2. 確認可在電視上開啟系統「預設首頁／Home app」選擇器。若沒有可靠入口，不要直接切換；不假設離線回退可用。
3. 核對自己建置／信任來源APK的版本、SHA256與憑證。未簽章APK不能安裝；不同簽章不能覆蓋同套件。
4. 先用一般App方式開啟，確認DPAD、Back、設定與所有App可操作，再由使用者自行選取預設HOME。
5. 選取後按實體Home，確認去向。測試自己使用的App及返回；異常即停止。

ADB安裝或HOME命令僅在你知道當次端點與套件身分、且已批准設備寫入時使用；本儲存庫不附掃網段、升權、停用原廠Launcher或自動指派腳本。

回退優先使用電視系統的預設首頁選擇器，選回原廠Launcher，再按實體Home確認。ADB可用時，進階使用者可針對已核對的原廠元件採用系統支援的set-home-activity；不同廠牌命令／Role支援可能不同，不在此寫入某一台私人設備的固定IP或元件。

如果ADB失聯、選擇器不可用或無法開機，不能假設回退已成功。保留原始現象，停止重試，依自己已驗證的設備救援流程處理。首頁備份不是完整韌體映像，本專案不提供通用刷機救援。

只有確實回原廠HOME並可操作後，才自行決定是否清理額外測試App。卸載會失去該App私有資料；不要在未備份時清資料或移除正在使用的首頁。
