# Excluded material and corrected artwork decision

Keys/passwords, Keychain setup, raw device logs, HOME test receipts, factory recovery archives, partitions, private user-selected images and media credentials remain excluded.

The original default artwork is now included. The owner confirmed on 2026-11-03 that these are project-generated/owned assets and authorized MIT redistribution. Files are restored byte-for-byte from the pre-public v71 resources; existing upstream attribution is preserved. See original-artwork-permission.json and manifest.json.

Beta1's earlier procedural replacement was rejected by the owner and is not the intended default. The procedural sample generator now writes only to a build preview directory and refuses to overwrite app resources. Historical Beta1 APK/source archives are preserved with a visual-rejection addendum.

The inherited automatic install scripts and private one-off incident bindings remain excluded/synthetic. The repository does not supply vendor apps, firmware, credentials or hardware recovery guarantees.
